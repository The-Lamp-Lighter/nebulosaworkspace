1Welcome to the Nebulosa Workspace

The Nebulosa Workspace is a suite of free, lightweight, open-source web applications, built to run right in your browser, on any computer, with no installation needed.

It is organized into three themes — Productivity, Creativity and Lifestyle.

The ecosystem brings together accessible tools to simplify your daily tasks, from editing documents and creating videos to organizing your finances and your cooking.

Explore our themes and discover how the Nebulosa Workspace can boost your ideas.

Authors and creators: Márcio Willians Barreto de Andrade and Raul Goulart de Andrade. Production team: Lamp Lighter Production Team.

3How to open it

  • From the website: open the Nebulosa Workspace address in the browser (updated Chrome, Edge, Firefox or Safari). There is nothing to install.
  • Each program on its own: each one has its own address, for example …/apps/stardust/, and works outside the Workspace.
  • Single HTML file: each program can also be downloaded as a single .html file, which opens with a double-click, offline.

4The home page

  • Search (Alt+K): find a program or an action by typing what you want to do — “spreadsheet”, “slides”, “sheet music”, “recipe”, “video”… It also does tasks (see Search and tasks).
  • The Workspace introduction and, next to it, the logo: the nebula with the icons of the 9 programs in orbit. It appears light or dark according to the theme; to download the logo (PNG with a transparent background), use About the Workspace › Download logo.
  • Tip of the day: one feature of a program each day. Another tip shows the next one; the Open… button takes you straight to that program.
  • Pick up where you left off: the most recently used programs.
  • Recent files: the latest files opened and saved in each program. Click to continue: when the browser allows it (Chrome and Edge, with the system “Open” window), the file reopens directly; otherwise the program opens and reminds you to use its Open button. The × removes a file from the list and Clear the list removes everything. Only the file name is kept, in this browser.
  • The cards are separated by the three themes: Productivity & Data, Media & Creativity and Art & Lifestyle. Each card shows the program’s practical purpose; click to open.
  • Utilities: right below the themes, the mini tools (see Utilities).
  • Footer: shortcuts, the Workspace version and the discreet Manuals, Visits, What’s new and Backup links, plus the legal texts.

5Opening and switching programs

  • Open from the side menu, the cards or search. Each open program becomes a tab at the top; click to switch and on the × to close. On phones, the tabs have their own row, right below the top bar.
  • If the program has changes not saved to a file, the Workspace asks before closing the tab.
  • Shortcuts: Alt+1…9 open the programs in menu order (Typee, Flyde, Stardust, EmCanto, LêPraMim, PazNoBolso, #pratododia, Imaginarium and Fluxo); Alt+0 goes back home. Utilities are not part of these shortcuts.
  • Resting programs: a program hidden for more than 30 minutes, with nothing pending or playing, rests to save the computer’s memory. This only happens with programs that reopen where they were last saved (Typee, Flyde, LêPraMim and Utilities). The tab is dimmed and a zz appears in the menu; click it and it wakes up.
  • Full screen: button in the top right corner.
  • Help menu: every program has a Help menu (or button) with, separately, the User manual, the Keyboard shortcuts (when the program has them), the Terms of use, Privacy, Credits and licenses and 🌐 Language, plus each program’s own items. The content opens in a window inside the program itself, which also has a Report a problem button.

6Utilities

Utilities live in a place separate from the main programs: their own item at the end of the side menu and a section on the home page. They open in a tab, like the programs, with the list of tools on the left (on phones, at the top). Everything happens in the browser: no file, text or password is sent anywhere. Full manual: Utilities.

  • QR code: links, text, Wi-Fi, contacts, email and WhatsApp, as PNG or SVG.
  • Unit converter: lengths, areas, volumes, weights, temperature, speed, time, data, cooking, energy, pressure and fuel economy.
  • Images: compress, resize and convert photos (JPEG, WebP, PNG), one or many at a time.
  • Password generator: strong passwords and passphrases, with the estimated strength.
  • Word counter: words, characters, sentences, reading time and social media limits.
  • Colors: HEX, RGB, HSL and CMYK, palettes and accessibility contrast.
  • PDF: merge (images too), split, rotate and sign.
  • Tasks and notes: To do / Doing / Done board and loose notes.
  • Whiteboard: sketches, shapes, arrows, sticky notes and flowcharts.

7Send to…

The Send to… button at the top appears when the program on screen has something to take to another one. Choose what to send and where to: the Workspace opens the other program (if it isn’t open yet) and delivers the content. Programs that don’t accept that kind of content don’t even show up in the list.

8Search and tasks

Search (Alt+K, or the field on the home page) also understands what you want to do. Type, for example:

  • “convert PDF to Word”: choose the PDF; Typee opens with it, and you just save it as .docx.
  • “merge PDFs”, “split PDF”, “sign PDF”: opens the right tool in Utilities.
  • “QR code”, “compress image”, “password”, “count words”, “convert units”.
  • “open spreadsheet”, “listen to a book”, “edit video”: choose the file and the right program opens with it.
  • “backup”, “restore”, “report problem”, “what’s new”.

Results with the words in their title come first.

9Appearance and language

  • The Appearance button switches the look of the program on screen between its original look and Nebulosa Default (purple #A778FF, navy blue #323559, orange #FF9C54 and yellow #FEFF36).
  • The Language button (🌐), next to Appearance, switches the menus and texts of all programs between Português do Brasil (the default), English and Español. The change is instant, without losing what is open, and the choice is remembered. Inside each program, the same selector is in Help › 🌐 Language.
  • What you write in your files is not translated. Numbers and amounts keep the Brazilian format (comma as decimal separator, R$ in Paz no Bolso).
  • Use Nebulosa Default in all applies the same look to all programs; Back to each one's default undoes it.
  • The Workspace itself has dark and light modes.

10Contact us

Questions, suggestions, ideas or a problem? Write to nebulosaworkspace@gmail.com.

  • At the top of the Workspace, the envelope button (before the bell) opens the Contact us panel: write through Gmail or Outlook in the browser, through the computer's e-mail program, or copy the address.
  • The same contact is at the end of the About the Workspace window.
  • Report a problem: in the same panel (and in each program’s Help menu), it opens an email already filled in with the technical details — version, program, language, browser and screen size. None of your files are sent.

11Notifications

Notices appear in the top right corner and disappear by themselves (they stay while the mouse is over them). The bell keeps the history, with the number of new notices. The programs also notify you here — for example, LêPraMim when an audiobook is ready and Stardust when a spreadsheet is saved.

12Donate with Pix

The Nebulosa Workspace is free and made by volunteers. The Donate with Pix button, at the end of the side menu (on phones, the heart in the top bar), opens the support window with the QR Code and the Pix copy-and-paste code (Pix is Brazil's instant payment system).

A discreet reminder appears in the corner a few seconds after a program saves or exports a file — at most once a day, and never with a window open or with the tab hidden. Whoever copies the Pix code gets 3 days without reminders.

13Visits

The visit counter is a Nebulosa Workspace statistic, made at the source: it counts the visits to the nebulosaworkspace.com.br domain, adding up all visitors, and keeps the overall history separated by page — the Workspace home page and each program. It is not a count of each person nor for each person.

  • Domain visits: adds 1 for the first page of the site opened in each browser session, whether the home page, a program, a manual or a legal page.
  • Per page: the home page and each program count at most once per browser session (reloading does not add again).
  • Only visits through the official address count; copies of the site at other addresses and tests on your own computer are not included in the statistic.
  • The count uses a free counter service that stores only one number per counter — no data about who visits. The Visits button, in the home page footer, shows the updated numbers; if the service is down, it says so and asks you to try again.

14Your data

Nothing you write, calculate, edit, film or listen to is sent to the internet. Each program keeps its preferences and backup copies in your browser, and saves your work in files on your computer (Word, Excel, PDF, PSD, video…).

The copies kept in the browser are tied to the site address and the browser. Clearing the browsing data deletes these copies — so always save to a file.

Backup

In About the Workspace › Backup (or in the footer, or by searching “backup”) you save to a file everything the Workspace and the programs keep in this browser: preferences, texts, tasks, notes and recovery copies — and, if you want, the files kept by the programs (LêPraMim books and audio, Fluxo projects…). To take it to another computer or browser, use Restore there: what is in the browser is replaced by the backup and the page reloads. Files you already saved on your computer (Word, Excel, PDF…) are not included, because you already have them.

No internet

After the first visit, the browser keeps a copy of the Workspace and of each program you open — including what the program only uses now and then, such as the PDF reader, and its manual. If the internet drops, what was already opened keeps working; a notice shows when the connection drops and when it comes back. A program never opened before needs internet the first time; without it, the offline notice appears with a Try again button. EmCanto’s text recognition (OCR) is also downloaded the first time you use it. This doesn’t install anything on the computer.

Recent files

The recent files list keeps only the file name and the program, in this browser. In Chrome and Edge, when the file was opened with the system “Open” window, the browser also keeps the permission to reopen it (it asks first).

16Frequently asked questions

Do I need to install anything?

No. Everything runs in the browser.

Does it work offline?

Yes. Once opened with internet, the Workspace and the programs keep working when the connection drops. The single HTML files open directly from the computer, without internet. Some things use the internet only when you ask or the first time, such as LêPraMim’s neural voice and EmCanto’s text recognition (OCR).

A program does not open and “I did not find…” appears.

The program's folder was not uploaded to the site with the right name. Whoever maintains the site should check the folder in apps/ (uppercase and lowercase matter).

Can I use the programs in English or Spanish?

Yes: use the Language button (🌐) at the top of the Workspace, or Help › 🌐 Language inside any program.

How do I suggest improvements or report a problem?

Write to nebulosaworkspace@gmail.com (envelope button at the top of the Workspace). If you can, support with a Pix: donations become development time.

A program shows as “resting”.

It was hidden and unused for more than 30 minutes and was closed to save memory. Nothing was lost: click Wake up (or the tab) and it opens where it was last saved.
