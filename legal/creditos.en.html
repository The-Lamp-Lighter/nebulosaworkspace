3Voices

Brazilian Portuguese neural voices from the Piper project (Cadu, Faber, Jeff and Edresson), from the rhasspy/piper-voices repository (MIT license), trained on datasets released into the public domain (CC0), such as NabuCasa's. Downloaded from Hugging Face only when you choose to use the voice.

4Fonts

Fonts from Google Fonts, almost all under the SIL Open Font License 1.1 (some, such as Roboto Mono, under Apache 2.0): Figtree, Jura, Inter, Instrument Sans, Unbounded, Montserrat, Poppins, DM Sans, DM Serif Display, Literata, Bebas Neue, Anton, Oswald, Archivo Black, Kanit, Teko, Russo One, Playfair Display, Cinzel, Pacifico, Lobster, Caveat, Dancing Script, Permanent Marker, Bangers, Orbitron, Audiowide, Press Start 2P, Righteous, Monoton, Rubik Mono One, Black Ops One, Bungee, Space Grotesk, Syne, Roboto Mono and others. Emojis use your own system's emoji fonts.

5Media formats

H.264, H.265, VP9 and AV1 videos are encoded with the browser's own features (WebCodecs). Fluxo's muxers (MP4, MOV, MKV, WebM, AVI) and ProRes encoder were written for the project. ProRes is a trademark of Apple Inc.; Fluxo is not licensed or endorsed by Apple. MP3 patents have expired.

6Services

Hosting: GitHub Pages. Visit counter: Abacus (abacus.jasoncameron.dev). Component distribution: jsDelivr, cdnjs, Hugging Face. We thank all these projects.
